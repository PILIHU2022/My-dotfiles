# tmux 配置与键位指南

本包提供一份可直接使用的 tmux 配置：保留标准 `C-b` 前缀，增加 Vim 风格窗格操作，并用内置颜色实现 Catppuccin Mocha 主题。配置不依赖 TPM（tmux 插件管理器）、Catppuccin 插件或网络下载。

## 文件与部署

配置文件位于 `tmux/.config/tmux/tmux.conf`，Stow 后部署为 `~/.config/tmux/tmux.conf`。

```bash
# 在仓库根目录预览并安装
stow -d . -t ~ -n -v tmux
stow -d . -t ~ tmux

# 启动、重连与卸载
tmux new -s main
tmux attach -t main
stow -d . -t ~ -D tmux
```

tmux 会优先读取 `~/.tmux.conf`。若该文件已存在，先备份或移走；也可以显式加载本配置：

```bash
tmux -f ~/.config/tmux/tmux.conf
```

配置在 tmux 3.5a 上校验。修改后按 `C-b r` 重新加载，无需重启会话。

## 键位表示法

`C-b` 表示按住 `Ctrl` 再按 `b`，松开后按下一个键。例如 `C-b c` 是 `Ctrl+b`，松开，再按 `c`。`C-b C-b` 会把一个原始 `C-b` 发送给窗格内的程序。

| 操作 | 键位 | 说明 |
| --- | --- | --- |
| 帮助 | `C-b ?` | 查看当前全部键位 |
| 命令模式 | `C-b :` | 输入 tmux 命令 |
| 重载配置 | `C-b r` | 重新读取本配置 |
| 分离会话 | `C-b d` | 保留会话并返回 shell |

## 窗口

| 键位 | 意义 |
| --- | --- |
| `C-b c` | 在当前目录新建窗口 |
| `C-b n` / `C-b p` | 下一个 / 上一个窗口 |
| `C-b 1` … `C-b 9` | 按编号切换窗口；编号从 1 开始 |
| `C-b Tab` | 返回上一次使用的窗口 |
| `C-b w` | 选择窗口或会话 |
| `C-b ,` | 重命名当前窗口 |
| `C-b &` | 关闭当前窗口（需确认） |

## 窗格

| 键位 | 意义 |
| --- | --- |
| `C-b %` 或 `C-b \|` | 左右分屏 |
| `C-b "` 或 `C-b -` | 上下分屏 |
| `C-b h/j/k/l` | 向左 / 下 / 上 / 右切换窗格 |
| `C-b H/J/K/L` | 向左 / 下 / 上 / 右调整大小，可连续按键 |
| `C-b z` | 最大化 / 还原当前窗格 |
| `C-b x` | 关闭当前窗格（需确认） |
| `C-b o` | 循环切换窗格 |
| `C-b {` / `C-b }` | 与相邻窗格交换位置 |
| `C-b Space` | 切换窗格布局 |

新建窗口和分屏都继承当前目录；`C-b c` 与两种分屏快捷方式均可直接复用当前工作路径。

## 会话与复制

| 键位 | 意义 |
| --- | --- |
| `C-b s` | 列出并切换会话 |
| `C-b $` | 重命名当前会话 |
| `C-b [` | 进入复制模式 |
| `v` / `y` | 复制模式中开始选择 / 复制并退出 |
| `/` / `n` / `N` | 搜索 / 下一个 / 上一个匹配项 |
| `Esc` | 退出复制模式 |
| `C-b ]` | 粘贴最近的缓冲区 |

鼠标已启用。拖拽选择后松开即复制，滚轮可进入历史记录；复制依赖终端支持 OSC 52（kitty 支持）。若系统剪贴板未更新，检查终端设置或使用 `C-b ]` 粘贴 tmux 缓冲区。

## Catppuccin Mocha 主题

主题直接使用 Catppuccin Mocha 色值，而不是加载外部插件：

- 背景使用 Mantle `#181825`，文字使用 Text `#cdd6f4`。
- 会话标签使用 Mauve `#cba6f7`，当前窗口使用 Blue `#89b4fa`。
- 非活动窗口、消息框和选中项使用 Surface 色系。
- 活动窗格边框为蓝色，搜索命中为黄色 `#f9e2af`。

若十六进制颜色显示异常，确认终端和 `$TERM` 支持真彩色；配置已为 `xterm-256color` 启用 `Tc` 能力。
