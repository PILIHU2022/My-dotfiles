# tmux 按键详细说明

本文逐项说明 `tmux/.config/tmux/tmux.conf` 的按键绑定。配置与环境说明见
[tmux-configuration.md](tmux-configuration.md)。

本地终端的 tmux 前缀为 `C-a`，SSH 会话中的 tmux 前缀为 `C-b`。下文默认以
本地 `C-a` 为例；SSH 到 VPS 后，请把所有 `C-a` 替换为 `C-b`。状态栏左侧会
显示当前实际前缀。

每张表的三个字段含义如下：

- `按键`：先按前缀，松开后再按的键。
- `操作`：按键立即执行的动作。
- `后续使用与切换`：执行后停留在哪里，以及接下来按什么键继续操作。

进入帮助、会话树、复制模式或命令提示符后，按键直接作用于当前界面，通常不再
需要前缀；退出这些界面后再使用 `C-a`。

## 前缀与通用操作

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a` | 进入 tmux 前缀等待状态 | 松开后按 `c`、`n`、`s`、`S` 等；不确定下一键时按 `?` 查看。单独按 `C-a C-a` 可发送原始前缀。 |
| `C-a C-a` | 向当前程序发送原始 `C-a` | 发送后仍停留在当前窗格，可直接继续输入；SSH 中对应 `C-b C-b`。 |
| `C-a ?` | 列出当前全部键位 | 列表内用 `j` / `k` 或方向键移动，`q` 或 `Esc` 关闭；关闭后回到原窗格，前缀仍是 `C-a`。 |
| `C-a :` | 打开 tmux 命令提示符 | 输入命令后按 `Enter` 执行；按 `C-c` 取消；执行完回到当前窗格。 |
| `C-a r` | 重新加载 tmux 配置 | 状态栏显示重载信息，当前窗口和窗格不变；随后可直接继续使用新键位。 |
| `C-a d` | 分离当前客户端 | 返回 shell，会话继续在后台运行；用 `tmux attach -t <会话名>` 重新进入。 |

## 会话树

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a s` | 打开会话树并切换到所选会话 | 用 `j` / `k` 或方向键移动光标，按 `Enter` 切换并关闭会话树；按 `q` 或 `Esc` 取消。切换后仍使用当前前缀。 |
| `C-a S` | 打开会话树并重命名光标所在会话 | 移动光标到目标会话，按 `Enter` 打开 `Rename selected session:` 提示；输入新名称后按 `Enter` 执行，按 `C-c` 取消。完成后回到原窗格；需要切换会话时再用 `C-a s`。 |

会话树打开后，以下按键不需要前缀：

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `j` / `k` 或 `Down` / `Up` | 向下 / 向上移动光标 | 到达目标会话后按 `Enter`；在 `C-a s` 中切换，在 `C-a S` 中重命名。 |
| `Enter` | 选择光标所在项 | `C-a s` 会切换到该会话；`C-a S` 会打开重命名提示。 |
| `h` / `l` 或 `Left` / `Right` | 折叠 / 展开当前项 | 折叠后可继续用 `j` / `k` 移动；再按 `l` 展开。 |
| `x` | 删除光标所在项 | 出现确认提示时按 `y` 删除，按 `n` 取消；删除后光标留在会话树中。 |
| `t` / `T` | 标记 / 清除全部标记 | 标记后可按 `:` 对当前项或全部标记项执行命令。 |
| `:` | 对当前项或标记项执行 tmux 命令 | 输入 `rename-session <新名称>` 后按 `Enter`，可直接重命名光标所在会话或全部标记会话；按 `C-c` 取消。 |
| `r` | 反转当前排序 | 会话列表立即重新排序，光标仍可用 `j` / `k` 移动；按 `q` 退出。 |
| `O` | 切换排序字段 | 在索引、名称、活动时间之间切换；随后用 `j` / `k` 选择。 |
| `q` 或 `Esc` | 关闭会话树 | 返回打开会话树前的窗格，不切换会话。 |

## 窗口

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a c` | 在当前路径新建窗口 | 新窗口立即成为当前窗口；按 `C-a p` 返回上一个窗口，按 `C-a Tab` 回到上次使用的窗口，或按 `C-a 1` … `C-a 9` 直接跳转。 |
| `C-a C` | 在当前路径新建会话 | 新会话创建并切换过去；按 `C-a L` 返回上一次会话，或用 `C-a s` 选择会话。 |
| `C-a n` / `C-a p` | 下一个 / 上一个窗口 | 第一次按键后可在 500 ms 内连续按 `n` / `p`；停止后可用 `C-a Tab` 返回上次窗口，或按编号跳转。 |
| `C-a 1` … `C-a 9` | 切换到指定编号窗口 | 编号从 `1` 开始；切换后用 `C-a Tab` 返回上一个窗口，或用 `C-a n` / `C-a p` 相对切换。 |
| `C-a Tab` | 返回上一次使用的窗口 | 再按一次 `C-a Tab` 会切回另一窗口；也可继续用 `C-a n` / `C-a p` 或编号切换。 |
| `C-a w` | 打开窗口/会话选择树 | 用 `j` / `k` 或方向键移动，按 `Enter` 切换；按 `q` 或 `Esc` 取消，之后回到原窗口。 |
| `C-a ,` | 重命名当前窗口 | 输入新名称后按 `Enter` 确认，按 `C-c` 取消；重命名后可用 `C-a w` 或 `C-a n` / `C-a p` 检查并切换。 |
| `C-a &` | 关闭当前窗口 | 出现确认提示时按 `y` 关闭，按 `n` 取消；关闭后 tmux 会切到另一个窗口，可用 `C-a w` 或 `C-a n` / `C-a p` 继续切换。 |
| `C-a f` | 按名称查找窗口 | 输入关键字后按 `Enter` 跳转；需要返回时按 `C-a Tab`，或重新用 `C-a w` 选择。 |

## 窗格

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a %` 或 `C-a \|` | 左右分屏 | 新窗格立即成为当前窗格；按 `C-a h` / `C-a l` 在左右窗格间切换，按 `C-a z` 最大化查看，按 `C-a x` 关闭。 |
| `C-a "` 或 `C-a -` | 上下分屏 | 新窗格立即成为当前窗格；按 `C-a k` / `C-a j` 在上下窗格间切换，按 `C-a z` 最大化查看，按 `C-a x` 关闭。 |
| `C-a h` / `C-a j` / `C-a k` / `C-a l` | 向左 / 下 / 上 / 右切换窗格 | 可在 500 ms 内连续按方向键移动；按 `C-a q` 显示编号后直接按编号跳转，按 `C-a ;` 返回上一个窗格。 |
| `C-a H` / `C-a J` / `C-a K` / `C-a L` | 向左 / 下 / 上 / 右调整窗格大小 | 可在 500 ms 内连续调整；调整后按 `C-a z` 放大检查，或按 `C-a Space` 切换布局。 |
| `C-a z` | 最大化 / 还原当前窗格 | 再按一次 `C-a z` 还原；放大期间仍可用 `C-a h/j/k/l` 切换窗格，切换后按 `C-a z` 可重新放大。 |
| `C-a x` | 关闭当前窗格 | 出现确认提示时按 `y` 关闭，按 `n` 取消；关闭后相邻窗格成为当前窗格，可用 `C-a h/j/k/l` 继续切换。 |
| `C-a o` | 循环切换窗格 | 连续按 `C-a o` 依次前进；到达目标后可用 `C-a z` 放大，或用 `C-a x` 关闭。 |
| `C-a ;` | 返回上一次使用的窗格 | 再按一次会切回另一窗格；也可用 `C-a h/j/k/l` 或 `C-a q` 加编号跳转。 |
| `C-a q` | 显示窗格编号 | 屏幕短暂显示编号，直接按对应数字跳转；按其他键取消，之后继续用 `C-a h/j/k/l` 切换。 |
| `C-a {` / `C-a }` | 与上一个 / 下一个窗格交换位置 | 交换后当前窗格保持选中；用 `C-a h/j/k/l` 检查相邻窗格，或按 `C-a Space` 重排布局。 |
| `C-a Space` | 切换到下一种窗格布局 | 可连续按 `C-a Space` 轮换布局；选定后按 `C-a z` 放大查看，或按 `C-a H/J/K/L` 微调大小。 |
| `C-a !` | 将当前窗格拆分为独立窗口 | 新窗口生成后可用 `C-a w` 查看，或按 `C-a n` / `C-a p` 切换；原会话继续保留该新窗口。 |

## 会话

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a )` / `C-a (` | 下一个 / 上一个会话 | 可在 500 ms 内连续按 `)` / `(`；到达目标后按 `C-a L` 返回上次会话，或按 `C-a s` 打开会话树确认。 |
| `C-a $` | 重命名当前会话 | 输入新名称后按 `Enter` 确认，按 `C-c` 取消；重命名后按 `C-a s` 可在会话树中看到新名称。 |
| `C-a L` | 切换到上一次使用的会话 | 再按一次会切回另一会话；也可用 `C-a s` 选择其他会话，或用 `C-a )` / `C-a (` 相对切换。 |
| `C-a D` | 从客户端列表中选择并分离 | 用 `j` / `k` 或方向键选择客户端，按 `Enter` 分离；按 `q` 或 `Esc` 取消。分离后回到 shell，可用 `tmux attach` 重新连接。 |

在已有会话间切换时，`C-a s` 用于选择会话，`C-a S` 用于重命名光标所在会话；
两者互相独立，重命名完成后不会自动切换会话。

## 复制模式与缓冲区

| 按键 | 操作 | 后续使用与切换 |
| --- | --- | --- |
| `C-a [` | 进入复制模式 | 用 `j` / `k`、`Ctrl+u` / `Ctrl+d`、`g` / `G` 浏览历史；按 `v` 开始选择，按 `Esc` 退出。 |
| `v` | 开始选择文本 | 用方向键或 `h/j/k/l` 扩展选择；按 `y` 复制并退出，按 `Esc` 取消选择。 |
| `y` | 复制选择并退出复制模式 | 先按 `C-a h/j/k/l` 切到目标窗格，再按 `C-a ]` 粘贴；也可用 `C-a =` 选择其他缓冲区。 |
| `/` / `?` | 向前 / 向后搜索 | 输入关键字后按 `Enter`；用 `n` / `N` 跳到下一个 / 上一个匹配项，按 `Esc` 退出复制模式。 |
| `n` / `N` | 下一个 / 上一个匹配项 | 继续按 `n` / `N` 循环查找；需要重新搜索时按 `/` 或 `?`，退出时按 `Esc`。 |
| `Ctrl+u` / `Ctrl+d` | 向上 / 向下翻半页 | 继续按可连续滚动；用 `v` 开始选择，或按 `Esc` 退出复制模式。 |
| `g` / `G` | 跳到历史缓冲区顶部 / 底部 | 到达边界后用 `j` / `k` 微调，按 `v` 选择，或按 `Esc` 退出。 |
| `Esc` | 退出复制模式 | 返回当前窗格，之后继续使用 `C-a` 前缀；需要粘贴时按 `C-a ]`。 |
| `C-a ]` | 粘贴最近的缓冲区 | 粘贴到当前窗格光标处；需要粘贴其他内容时按 `C-a =` 选择缓冲区。 |
| `C-a =` | 从缓冲区列表中选择并粘贴 | 用 `j` / `k` 或方向键选择，按 `Enter` 粘贴；按 `q` 或 `Esc` 取消。 |
| `C-a #` | 列出所有缓冲区 | 查看后可关闭列表；需要粘贴时回到窗格按 `C-a ]` 或 `C-a =`。 |

历史记录上限为 50000 行。复制依赖终端支持 OSC 52；kitty 已启用该能力。

## 鼠标

| 操作 | 后续使用与切换 |
| --- | --- |
| 左键单击窗格 | 该窗格成为当前窗格；之后可直接按 `C-a h/j/k/l` 切换，或按 `C-a z` 放大。 |
| 滚轮滚动 | 进入复制模式并浏览历史；按 `v` 选择、`y` 复制，或按 `Esc` 退出。 |
| 按住左键拖拽选择 | 松开后复制到 tmux 缓冲区并退出选择；切换到目标窗格后按 `C-a ]` 粘贴。 |
| 拖动窗格边框 | 调整窗格大小；松开后用 `C-a z` 检查效果，或按 `C-a Space` 切换布局。 |

鼠标拖拽可能受终端自身的选中/复制行为影响。以 kitty 为参考终端；其他终端若
拦截拖拽事件，可检查该终端的鼠标上报与剪贴板设置。
